Engines

LBM (M < 0.3): D2Q9 lattice-Boltzmann with Smagorinsky LES. Viscous and unsteady - Reynolds number is the physics knob; expect vortex shedding and stall-like separation. Forces via momentum exchange.

Euler (M 0.3-6): compressible finite-volume solver (MUSCL + HLLC). Captures shocks, expansion fans, transonic buffet, bow shocks. Inviscid: drag = wave drag only; the app adds an empirical friction Cd0 where relevant. Calorically perfect gas - above M~4-5 treat results as qualitative.

Theory: Hess-Smith panel method (+ Karman-Tsien compressibility) below M 0.7; Ackeret linearized theory above M 1.15; exact shock-expansion for the diamond airfoil. Instant, no GPU needed.

Validation

The Validation tab auto-compares each converged run against: Abbott & von Doenhoff wind-tunnel polars (NACA 0012/2412/4412, Re 6e6), RAE 2822 Case 6 (M 0.725), exact diamond-airfoil shock-expansion, Ackeret theory, and the panel method. Status: pass check off info.

Trust guide

Cl from LBM: good (~5-15%) for attached flow. Euler Cl below M~0.8 reads 30-40% low - the staircase surface weakens the Kutta condition; use LBM, the panel method, or supersonic cases where shocks set the load. Cd: trust LBM only at Re < ~1e5; at flight Reynolds numbers use the empirical estimate or wave-drag + friction. Staircase boundaries also inflate supersonic wave drag (~2x on thin sharp sections) - the "fine" grid helps all of this. No transition modeling, no real-gas effects.

Tips

Use ⏩ converge to run a case until forces settle - it stops automatically (cap ~40 chords of travel). The α-sweep runs each angle to convergence and pins the time-averaged result. Hover the flow field to probe local values (velocity, Cp, Mach, vorticity) and hover any plot for a crosshair readout. Mach & angle changes apply live - watch shocks move. Custom airfoils: paste any UIUC-format .dat file.
